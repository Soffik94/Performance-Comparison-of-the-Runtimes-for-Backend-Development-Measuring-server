# Runtime Benchmark Suite

This repository contains the measurement resources used to compare backend
applications running on Node.js, Deno, and Bun as part of a bachelor's thesis.

It includes benchmark scenarios, supporting scripts, monitoring configuration,
and dashboard definitions. The scenarios cover basic requests, computation,
database reads, and database writes.

Deployment-specific addresses, credentials, and generated measurement results
are intentionally excluded.

Further instructions are available in RUNBOOK.md. Information about result
visualization is provided in GRAFANA_PROMETHEUS_QUERIES.md.
